# moodymoose: a Hyprland Lua desktop

A from-scratch Hyprland setup on Arch Linux, written in Hyprland's Lua config
(0.55+) so the syntax is learned rather than copied. The design is modeled on
[LinuxBeginnings/Hyprland-Dots](https://github.com/LinuxBeginnings/Hyprland-Dots)
(the maintained, Lua-based successor of JaKooLit's Hyprland-Dots), but every
file here is built up piece by piece.

The core idea: **the wallpaper drives the theme.** One keypress picks a
wallpaper, and the window borders, rofi menus, kitty terminal and waybar all
recolor to match it.

---

## What is in the box

| Piece | Tool | Notes |
|---|---|---|
| Compositor | Hyprland (Lua config) | split into small modules |
| Wallpaper | hyprpaper | block-style `hyprpaper.conf` |
| Color engine | wallust 3.x | extracts a palette from the wallpaper, fills templates |
| Menus | rofi 2.x | wallpaper picker, app launcher, kitty theme picker |
| Terminal | kitty | follows the wallpaper via kitty's own `kitten themes` |
| Bar | waybar 0.15 | pill-style modules, colors from wallust |
| Notifications | dunst | started at login, not themed yet |

## Layout

```

│   ├── hyprpaper.conf            managed by wallpaper-select.sh (rewritten on every pick)
│   ├── moodymoose-configs/
│   │   ├── monitors.lua          hl.monitor
│   │   ├── env.lua               hl.env (cursor size)
│   │   ├── decoration.lua        gaps, borders, rounding, shadow, blur, animations
│   │   ├── settings.lua          layouts, misc, input, gestures
│   │   ├── rules.lua             window rules
│   │   ├── keybinds.lua          all key bindings
│   │   ├── autostart.lua         programs launched at login
│   │   ├── programs.lua          shared terminal / file manager / launcher commands
│   │   ├── palette.lua           loads colors.lua with fallback defaults
│   │   └── colors.lua            GENERATED by wallust, do not edit
│   └── moodymoose-scripts/
│       ├── wallpaper-select.sh   the wallpaper picker and theming pipeline
│       └── kitty-theme-picker.sh rofi picker for kitty themes
├── wallust/
│   ├── wallust.toml
│   └── templates/

│       ├── colors-rofi.rasi
│       ├── colors-kitty.conf
│       └── colors-waybar.css
├── rofi/
│   ├── wallpaper.rasi            3x3 thumbnail grid
│   ├── launcher.rasi             single-column app launcher
│   ├── kitty-theme.rasi          3-column theme list
│   └── wallust-colors.rasi       GENERATED by wallust
├── kitty/
│   ├── kitty.conf                includes current-theme.conf
│   ├── current-theme.conf        the active theme (a copy, not a symlink)
│   ├── kitty-themes/             ~200 themes (+ generated 01-Wallust.conf)
│   └── themes/Wallust.conf       GENERATED, used by `kitten themes`
```

Files marked GENERATED are overwritten every time a wallpaper is picked.

## Dependencies

From the official repos:

```bash
sudo pacman -S hyprland hyprpaper rofi kitty waybar dunst \
    network-manager-applet libnotify wireplumber brightnessctl \
    playerctl dolphin fzf
```

From the AUR:

```bash
yay -S wallust        # the stable package; NOT wallust-git
```

Notes:

- **rofi 2.0 or newer** is required. Wayland support was merged into the main
  `rofi` package in 2.0.0, so the old `rofi-wayland` package is not needed.
- **wallust 3.x.** The wallust 4 line is a pre-release with an incompatible
  config format (`wallust migrate` converts it). The config here is for v3.
- `wpctl` (volume keys) comes from `wireplumber`; `notify-send` from `libnotify`.

## How it fits together

Pressing **`SUPER + W`** runs `moodymoose-scripts/wallpaper-select.sh`:

1. A rofi grid of thumbnails from `~/Pictures/wallpapers` (theme: `wallpaper.rasi`).
2. The choice is written into `hyprpaper.conf`, so it survives a re-login, and
   applied immediately with `hyprctl hyprpaper wallpaper ",<path>,cover"`.
3. The script checks whether kitty is currently on the wallust theme (by looking
   for the `## name: Wallust` marker in `current-theme.conf`). This has to
   happen before wallust rewrites the theme file.
4. `wallust run` extracts a palette from the new image and renders every
   template: Hyprland (`colors.lua`), rofi (`wallust-colors.rasi`), kitty
   (`Wallust.conf` and `01-Wallust.conf`) and waybar (`colors.css`).
5. If kitty was on the wallust theme, it is re-applied to every open window with
   `kitten themes --reload-in=all Wallust`. Any other theme is left alone.
6. waybar is restarted so it reads the new `colors.css`.
7. `hyprctl reload` runs last, so Hyprland re-reads `colors.lua` and the window
   borders update.

### Colors in the Hyprland config

`palette.lua` loads the generated `colors.lua` inside `pcall`, so a missing or
broken file falls back to defaults (the original cyan-to-green look) and never
stops the config from loading. `decoration.lua` then uses it:

- active border: a 45-degree gradient from `color12` to `color13`
- inactive border: `color0`

### wallust configuration

`~/.config/wallust/wallust.toml`:

```toml
backend     = "fastresize"
color_space = "labmixed"
palette     = "dark16"
threshold   = 11

[templates]
hypr.template         = 'colors-hyprland.lua'
hypr.target           = '~/.config/hypr/moodymoose-configs/colors.lua'
rofi.template         = 'colors-rofi.rasi'
rofi.target           = '~/.config/rofi/wallust-colors.rasi'
kitty.template        = 'colors-kitty.conf'
kitty.target          = '~/.config/kitty/themes/Wallust.conf'
kitty-picker.template = 'colors-kitty.conf'
kitty-picker.target   = '~/.config/kitty/kitty-themes/01-Wallust.conf'
waybar.template       = 'colors-waybar.css'
waybar.target         = '~/.config/waybar/colors.css'
```

The kitty template is rendered twice on purpose. `Wallust.conf` is what
`kitten themes` uses; `01-Wallust.conf` shows up in the custom kitty theme
picker and in `kitty-theme-select`. Both carry the same marker line.

Run wallust by hand (for example after a fresh install) with:

```bash
wallust run -s --templates-dir ~/.config/wallust/templates ~/Pictures/wallpapers/<image>
```

| volume, mute, mic, brightness keys | `wpctl` / `brightnessctl` |
| media keys | `playerctl` |

## Components in detail

### Hyprland config modules

`hyprland.lua` loads, in order: `monitors`, `env`, `decoration`, `settings`,
`rules`, `keybinds`, `autostart`. `programs` and `palette` are not listed
because they only return tables and load the first time another file
`require`s them.

Current look: `gaps_in 5`, `gaps_out 15`, `border_size 3`, rounding 10, blur
and shadow on, dwindle layout.

`programs.lua` holds the default programs (kitty, dolphin, and the rofi
launcher command) in one place:

```lua
return {
  terminal    = "kitty",
  fileManager = "dolphin",
  menu        = "pkill rofi || rofi -show drun -theme $HOME/.config/rofi/launcher.rasi",
}
```

### Autostart

`nm-applet`, `waybar`, `hyprpaper` and `dunst`, started from
`hl.on("hyprland.start", ...)` so they run once per session and not on every
config reload.

### Kitty

`kitty.conf` includes `current-theme.conf`, which is a plain copy of whichever
theme is active. Three ways to change it:

- **`SUPER + CTRL + K`**: the rofi picker. Enter applies and exits, `Alt+P`
  previews and reopens the menu, `Esc` cancels and restores the theme you
  started with. The first entry, "Set by wallpaper", is the wallust theme.
- **`kitty-theme-select`**: the original fzf script in `~/.local/bin`.
- **`kitten themes`**: kitty's built-in tool; it also sees the `Wallust` theme
  in `~/.config/kitty/themes/`.

The wallpaper picker only touches kitty when it is already on the wallust theme,
so a theme chosen on purpose is never overridden.

### Rofi

Three themes, all importing `wallust-colors.rasi`: `wallpaper.rasi` (thumbnail
grid), `launcher.rasi` (list of apps with icons) and `kitty-theme.rasi`
(text-only grid). The menus show the colors from the previous wallpaper pick,
because wallust runs after the choice is made.

### Waybar

Left: workspaces 1 to 5 (always shown) and the focused window title. Center:
clock. Right: volume, network, CPU, memory, tray. Every module is a rounded pill
with an accent border, colored from `colors.css`. Labels are text only; icons
need a Nerd Font and have not been added yet.

## Customizing

- **Autostart something:** add the command to the `startup` list in `autostart.lua`.
- **Change a default program:** edit `programs.lua`.
- **Add wallpapers:** drop images into `~/Pictures/wallpapers`.
- **Change which palette colors the borders use:** edit the `col` block in
  `decoration.lua` (any of `color0` to `color15`, `background`, `foreground`).
- **Theme another app:** add a template to `~/.config/wallust/templates`, add a
  `name.template` / `name.target` pair to `wallust.toml`, import the generated
  file from the app's config, and add a reload line to `wallpaper-select.sh`.

## Lessons learned (things that bit during the build)

- **A `local` is only visible inside its own file.** Shared values live in
  `programs.lua` and are `require`d.
- **A bare `hl.exec_cmd` at the top level of a config file runs again on every
  reload.** Startup commands belong inside `hl.on("hyprland.start", ...)`.
- **`hl.exec_cmd` strings are glob-expanded by Hyprland.** Use `test -e file`
  instead of `[ -e file ]` inside those strings.
- **`pkill -USR1 kitty` also matches any script with "kitty" in its name,** so
  the script kills itself. Use `pkill -x kitty` for an exact name match.
- **wallust v3 and v4 configs are not compatible.** Install the AUR package
  `wallust`, not `wallust-git`.
- **Waybar did not reliably pick up an `@import`ed stylesheet on `SIGUSR2`.**
  The script restarts it instead.
- **The kitty marker (`## name: Wallust`) is what the script checks,** not file
  equality, so switching away and back never breaks the link.
- **Verify the file on disk, not the one you meant to save.** A stale copy of
  `wallpaper-select.sh` was missing the waybar and reload lines.
- `ls` is aliased to `lsd` on this machine, which rejects GNU flags such as
  `--time-style`; use `stat` or `command ls`.

## Troubleshooting

| Symptom | Check |
|---|---|
| Borders do not change after a wallpaper pick | `hyprctl reload` runs last in the script; `moodymoose-configs/colors.lua` should have a fresh timestamp |
| Waybar keeps old colors | `~/.config/waybar/colors.css` timestamp; the script should restart waybar |
| Kitty does not follow the wallpaper | `head -2 ~/.config/kitty/current-theme.conf` should start with `## name: Wallust`; if it is on another theme, that is by design |
| Rofi menu has no colors or errors | `~/.config/rofi/wallust-colors.rasi` must exist; run wallust once by hand |
| Wallust prints a template error | run it by hand and read the message; check `wallust --version` is 3.x |
| Wallpaper does not change | `hyprctl hyprpaper --help`; hyprpaper must be running and use the block-style config |
| Config error banner after editing | the banner names the file; the config is modular, so bisect by commenting out one `require` at a time |
